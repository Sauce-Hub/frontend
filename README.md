# 🍳 Sauce Hub – Frontend

Sauce Hub is a social recipe-sharing application where users can discover,
share, save, and interact with recipes.

The idea is similar to a social media application, but focused on cooking
and recipes.

Users can also suggest improvements to recipes. The recipe owner can review
the suggestion and decide whether to accept it.

---

## 💡 App Idea

Sauce Hub allows users to:

- Discover recipes
- Browse a personalized "For You" feed
- Search for recipes
- View detailed recipes
- Like and save recipes
- Comment on recipes
- Post their own recipes
- Chat with an AI recipe assistant
- Suggest improvements to other people's recipes
- Receive suggestions on their own recipes

## 📱 Main Screens

### Splash Screen

The first screen shown when opening the application.

---

### Authentication

Users can:

- Sign up
- Log in
- Enter their account information

---

### Home

The main feed where users can see recipes from accounts they follow.

Users can:

- Like recipes
- Save recipes
- Open recipe details
- View comments

---

### For You

A personalized recipe discovery page.

It includes:

- Search
- Recipe categories
- Recommended recipes
- Recipe cards

---

### Add Recipe

Users can create and publish their own recipes.

They can add:

- Recipe image
- Recipe name
- Category
- Ingredients
- Cooking steps

Ingredients and steps can be added one by one.

---

### Recipe Details

Shows the complete recipe.

It includes:

- Recipe image
- Recipe title
- Recipe creator
- Category
- Cooking time
- Difficulty
- Ingredients
- Cooking steps
- Likes
- Comments
- Save button
- Share button
- Suggest Improvement button

---

### Comments

Users can:

- View comments
- Add comments
- Reply to comments

---

### Suggest Improvement

Users can suggest changes to an existing recipe without directly changing
the original recipe.

They can:

- Add ingredients
- Delete ingredients
- Add cooking steps
- Delete cooking steps
- Send the suggestion to the recipe owner

The suggestion starts as **Pending**.

The recipe owner can later accept or reject it.

---

### Chat

An AI-powered recipe assistant.

Users can ask questions about recipes and receive useful suggestions.

The assistant can also recommend recipes from Sauce Hub.

---

### Profile

Users can view:

- Username
- Recipes
- Saved recipes

Users can also edit their profile.

---

🎯 Project Goal

The goal of Sauce Hub is to create a simple social platform for cooking
where people can discover recipes, share their own recipes, interact with
other users, and collaboratively improve recipes.

The main idea behind the application is:

Discover recipes. Share recipes. Improve recipes. 🍳
